# BindMatchCopy

本项目包含论文的模型、Bind/Match/Copy 测量、路径干预、训练控制和召回评估代码。安装及运行命令见 [README](README.md)。

- 正式评测统一为**每条件 200 个样本**：机制测量为 200 个配对 prompt；召回评估为总计 200 个 sequence。清洁可解子集来自这 200 条父样本，因此子集数量不必等于 200。
- 样本数在 `src/bindmatchcopy/protocol.py` 统一定义。CLI 只允许显式 `--demo` 使用更少样本。
- Transformer 和 SWA hybrid 按代码均为 **77,258,833（77.26M）参数**，对应论文已同步修订。
- `paper_data/v31/` 是用于绘图的历史导出数据；原始数值和实际记录数量保留。新配置不代表旧实验已经重跑。
- 项目只保留协议、数据格式和简短 smoke 检查，不包含本地工作日志、大量验证报告或测试权重。

目录按模型、数据、干预、测量、训练、评估和统计分工。真实论文权重、原分布式训练数据流水线及数据集由使用者另行提供。
